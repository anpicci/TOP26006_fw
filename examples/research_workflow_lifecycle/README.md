# Synthetic research workflow lifecycle

This teaching fixture has two distinct repository roles. Copy the existing
[`repeated_measurements`](../repeated_measurements/README.md) example into a
temporary **analysis repository**; copy `methods_seed/` into a separate
temporary **methods repository**. The numbers are invented. Neither copy is a
TOP-26-006 child repository or a governed new registry identity.

The bounded analysis exercise adds an interpretation note reporting the
existing script's result and its assumptions. It changes no data, code, or
tests. The methods exercise records only the qualified numerical evidence and
its limits. A reviewer checks each claim before a scientific owner accepts it.

Scratch Git histories used to demonstrate this workflow are disposable
diagnostic evidence. A commit in either history authorizes nothing in the
other. Do not use the fixture as a real-data method, publication claim, or
license grant.
