# TOP26006_fw

`TOP26006_fw` coordinates the TOP-26-006 analysis project. Its private GitHub
repository is [`anpicci/TOP26006_fw`](https://github.com/anpicci/TOP26006_fw).
It connects the project's analysis software, shared framework, fit software,
scientific documents, and supporting repositories while keeping each
repository's history and technical responsibilities independent.

The managed Glados checkout is `/users/apiccine/work/correction-lib`. This is
a local directory name, not the repository identity. A fresh clone contains
the tracked `TOP26006_fw` files; it does not include the independent
repositories available in the managed workspace.

## Start here

Read [Getting started](docs/getting_started.md) to identify the repository for
your task and find its native documentation. Check that the relevant
repository is available in your workspace before following its instructions.

For common tasks, use `topeft` for analysis, plots, datacard workflows, and
production; `EFTFit` for statistical fits; and the independent paper and
Analysis Note repositories coordinated locally under `ANDOCS`. `topcoffea`
provides shared framework mechanisms. The [task guide](docs/getting_started.md#where-to-go-for-common-tasks)
lists the native starting pages.
