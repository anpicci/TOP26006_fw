# Review returned evidence

**Problem:** an executor reports completion but acceptance is undecided.

Compare its claims with direct inputs, exact source identity, commands, output, and diff. Independently test the evidence appropriate to the question and check omissions, model assumptions, uncertainty, and scope. Record **blocking** findings that prevent the proposed acceptance and **nonblocking** findings that leave its bounded claim intact. Preserve valid evidence when a narrow repair is needed.

Use the [review template](../../templates/review_report.md). Name what was not evaluated. The reviewer recommends; the responsible owner decides [acceptance](record_a_result_acceptance.md). See [Tutorial 5](../tutorials/05_review_and_accept_returned_evidence.md).
