# Transfer project responsibility

**Problem:** a collaborator must continue without oral context.

Fill the [handoff template](../../templates/handoff.md): authority and scientific owner, accepted result and qualifications, current repository/branch/commit identity, evidence provenance, superseded material, residual mandate, blockers, invalidation boundary, checks not to repeat, and next actual decision. Cite artifacts that the recipient can reopen.

Ask the recipient to read and confirm understanding before a new task is dispatched. A handoff transmits evidence; it neither proves comprehension nor grants repository writes or scientific authority. [Tutorial 9](../tutorials/09_transfer_work_to_a_collaborator.md) uses the synthetic stopped-task case.
