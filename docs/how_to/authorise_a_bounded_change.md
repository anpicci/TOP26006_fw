# Authorise a bounded change

**Problem:** evidence supports a proposed correction, but the permitted effect is not yet defined.

The owner states the scientific or methodological purpose, exact writable repository and paths, fixed inputs, branch role, environment and network limits, validation claim, and stop conditions. The prompt author turns that effect boundary into a [bounded change contract](../../templates/bounded_change_prompt.md) under live [CPC.md](../../CPC.md). The executor performs only that contract and returns source identities, commands, outputs, diff, and limits.

Review the result independently. A successful local commit, test, or executor report is evidence; it cannot confer scientific acceptance or authorize effects in another repository. See [Tutorial 4](../tutorials/04_make_a_bounded_analysis_change.md).
