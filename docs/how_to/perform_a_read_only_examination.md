# Perform a read-only examination

**Problem:** a research question needs evidence before any change is justified.

Define the question, source paths, expected observations, validation ceiling, and report artifact. Authorize investigation_only under [AGENTS.md](../../AGENTS.md). Read source and live Git identity; run only explicitly permitted lightweight checks. Record commands, inputs, output, uncertainty, and what was not examined. Keep executor classifications separate from direct observations and independent review.

A read-only task grants no tracked edit, cleanup, production, remote write, or acceptance. If a defect is found, hand it to the owner as evidence for a **new bounded change decision**; do not turn the investigation into an unannounced fix.
