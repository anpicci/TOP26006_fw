# How to choose workspace and checkout names

Choose a directory you control, with enough space for the coordination files. Its name can be `research-coordination`, `project-notes`, or another sensible local name. Set `workspace_root` in your [profile](../reference/local_profile.md) to its absolute location. The name does not change the `TOP26006_fw` project identity or `repository_id`.

Keep paths to independent repositories separate. Confirm each Git root before use and consult [repository identity](../explanation/repository_and_workspace_identity.md). The local profile may point to an already-governed checkout; it does not add an identity to the [registry](../../governance/repositories.md).
