# Reuse prior evidence

**Problem:** a new task follows an already reviewed result.

Cite the accepted artifact and its exact claim, source identity, reviewer finding, and owner acceptance scope. State the **invalidation boundary**: changes to inputs, method, environment, Git identity, or assumptions that would break reuse. Recheck live facts that can drift. List accepted checks **not to repeat** while the boundary holds, and identify only the new evidence the delta needs.

Do not infer that every old live state still holds or that a partial finding erases valid evidence. [Tutorial 6](../tutorials/06_continue_from_existing_evidence.md) shows a provenance repair that preserved the numerical result.
