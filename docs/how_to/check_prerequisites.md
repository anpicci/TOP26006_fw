# How to check prerequisites

For the OpenAI/Codex reference procedure, obtain a TOP26006_fw checkout through the project access route documented in the [README](../../README.md#repository-visibility-and-licensing), and an already-prepared Python interpreter with PyYAML. Read access alone grants no permission to execute or modify project files. For example, if `/home/alice/work/TOP26006_fw` is your checkout, set `checkout` to that path, `cd "$checkout"`, and run `git rev-parse --show-toplevel`, `git branch --show-current`, and `git status --short`. The Git root should match the checkout path; branch and status are live local observations. Identify your interpreter's absolute path and test `import yaml` through your chosen wrapper; do not install packages as part of this route. Confirm you can read [AGENTS.md](../../AGENTS.md), [CPC.md](../../CPC.md), and the [project repository map](../../governance/repositories.md). A shell that can run `git` suffices for local readback.

The local command wrapper must accept a command and arguments, prepare any site-specific existing environment if needed, execute the command, and propagate its exit status. [Tutorial 1](../tutorials/01_prepare_a_research_project.md) provides a forwarding-only example for an already-prepared interpreter. If your interpreter cannot import PyYAML, obtain a project-approved prepared environment; do not silently change the software environment. A separate TOPEFT checkout is needed for the real repository lesson in [Tutorial 2](../tutorials/02_add_an_analysis_repository.md); the synthetic calculation in Tutorial 3 does not require it. For other providers, use [compatibility status](../reference/provider_compatibility.md).
