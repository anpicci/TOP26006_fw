# How to choose an AI tool for a research task

The human researcher or scientific owner defines the scientific purpose, permitted effects within their authority, and acceptance boundary. A coordinating Chat or authorized prompt author translates that mandate into an execution contract with scope, evidence, review, and stop conditions. A research/audit environment can inspect sources and produce evidence; a coding agent can implement an explicitly authorized change. A separately tasked reviewer assesses the returned evidence and recommends acceptance, repair, or stop. The human owner makes the final acceptance decision. Optional IDE assistance can help a person navigate or edit but grants no independent authority.

This manual documents an OpenAI/Codex reference procedure. Other providers may support similar methods but their instruction loading, sandbox, context, tool, model, and delegation behavior require separate verified adaptation. Consult [provider compatibility](../reference/provider_compatibility.md) and [roles](../explanation/roles_and_authority.md).
