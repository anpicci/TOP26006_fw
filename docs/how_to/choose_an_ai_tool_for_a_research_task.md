# How to choose an AI tool for a research task

First decide the scientific question, needed evidence, and who can review it. A human owner or coordinator frames the permitted work and acceptance boundary. A research/audit environment can inspect sources and produce evidence. A coding agent can implement an explicitly authorized change; optional IDE assistance can help a person navigate or edit but grants no independent authority.

This manual documents an OpenAI/Codex reference procedure. Other providers may support similar methods but their instruction loading, sandbox, context, tool, model, and delegation behavior require separate verified adaptation. Consult [provider compatibility](../reference/provider_compatibility.md) and [roles](../explanation/roles_and_authority.md).
