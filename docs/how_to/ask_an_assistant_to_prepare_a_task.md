# How to ask an assistant to prepare a research task

State the research question, exact repository and read-only or writable paths, available data and provenance, requested evidence, permitted effects, validation ceiling, reviewer, and stop conditions in the [research task request](../../templates/research_task_request.md). Ask the coordinator to bind the request to live [AGENTS.md](../../AGENTS.md) and [CPC.md](../../CPC.md), including the current mandatory prompt contract. The [read-only skeleton](../../templates/read_only_prompt.md) is illustrative only.

For the [synthetic example](../../examples/repeated_measurements/README.md), ask for a read-only arithmetic check of the CSV, formula, and script. Require exact command/output locators and a clear uncertainty statement. The executor's report is evidence; the [review template](../../templates/review_report.md) supports independent checking before a human acceptance decision.
