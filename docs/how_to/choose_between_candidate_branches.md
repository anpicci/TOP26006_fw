# Choose between candidate branches

**Problem:** more than one branch name could carry a proposed result.

Compare each candidate with the task's semantic surface and accepted feature work. Inspect live HEADs, ancestry, relevant diff, and the [module's branch roles](../../governance/repositories.md) where applicable. Record positive evidence for applicability or non-applicability. One applicable feature branch calls for continuation; multiple require a declared reconciliation decision. An uncertain comparison is **ambiguous**, not proof that no applicable branch exists.

Do not create a parallel branch merely because its name is convenient. Use live [AGENTS.md](../../AGENTS.md) and [CPC.md](../../CPC.md) for the exact branch-policy and exception contract.
