# Getting started

You can learn the coordination workflow without an analysis checkout or real data. The [synthetic repeated-measurements example](../examples/repeated_measurements/README.md) supplies a small question, method, and checkable output.

The sequence is [prepare a research project](tutorials/01_prepare_a_research_project.md), [map an already-governed analysis repository](tutorials/02_add_an_analysis_repository.md), then [complete a read-only task](tutorials/03_complete_a_first_read_only_task.md). Tutorial 2 uses a local path example and does not require cloning or touching a child repository.

The method can be adapted to other AI providers, but the executable reference procedure is OpenAI/Codex. Provider mechanisms are not interchangeable by filename or label; see [compatibility](reference/provider_compatibility.md). The current private release and intended-license boundary is stated in the [root README](../README.md).

Keep four sources separate: the [typed registry](../governance/repositories.md) names stable repository roles; your ignored [local YAML profile](reference/local_profile.md) supplies installation paths; fresh Git commands show current branch and HEAD; the scientific owner decides whether evidence supports an accepted result. [Repository identity](explanation/repository_and_workspace_identity.md) explains the distinctions.
