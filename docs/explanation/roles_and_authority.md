# Roles and authority

The researcher or scientific owner chooses the question, method, interpretation, and acceptance boundary. A human coordinator turns a bounded request into an authorized prompt using live [CPC.md](../../CPC.md). The executor may inspect or edit only within the grant set by live [AGENTS.md](../../AGENTS.md) and applicable native policy. A reviewer independently tests the evidence and communicates findings; executor self-report is not acceptance.

A research/audit environment is useful for source and evidence inspection. A coding agent is appropriate only when a change has been explicitly authorized. Optional IDE assistance helps navigation and editing but grants no authority. [Choosing a tool](../how_to/choose_an_ai_tool_for_a_research_task.md) starts from the task and [provider status](../reference/provider_compatibility.md) limits concrete assumptions.
