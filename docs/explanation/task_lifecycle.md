# The task lifecycle

A research task starts with a question and a proposed evidence boundary. Before any change, the responsible owner determines the effect scope and the prompt author translates that scope into an executable contract. The executor observes or changes only the permitted surface and returns provenance and results. An independent reviewer examines those results; the owner accepts a defined claim or leaves it pending.

The lifecycle can continue without starting over. Accepted evidence remains usable while its inputs, assumptions, and source identity stay within a stated invalidation boundary. A bounded repair addresses only the open finding. A stopped task records its direct state and waits for a new decision; it does not rewrite the workspace to manufacture a pass.
