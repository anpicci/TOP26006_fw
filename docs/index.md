# Research-first manual

Follow the route in [Getting started](getting_started.md). Begin with a research question and evidence need; add tool details only when the work requires them.

## Learn in sequence

1. [Prepare a research project](tutorials/01_prepare_a_research_project.md): identify the coordination checkout, configure a local profile, and check its resolved paths.
2. [Add an analysis repository](tutorials/02_add_an_analysis_repository.md): follow the project repository map to a separate TOPEFT checkout and inspect one maintained dry-run entry point.
3. [Complete a first read-only task](tutorials/03_complete_a_first_read_only_task.md): use synthetic measurements, the companion notebook, and review evidence.
4. [Make a bounded analysis change](tutorials/04_make_a_bounded_analysis_change.md): state purpose, fixed inputs, permitted path, and evidence.
5. [Review and accept returned evidence](tutorials/05_review_and_accept_returned_evidence.md): separate output, findings, and owner decision.
6. [Continue from existing evidence](tutorials/06_continue_from_existing_evidence.md): preserve valid work while repairing provenance.
7. [Coordinate a sequential two-repository change](tutorials/07_coordinate_a_multi_repository_change.md): move qualified evidence between roles.
8. [Recover from a stopped task](tutorials/08_recover_from_a_stopped_task.md): preserve an unexpected local edit and stop.
9. [Transfer work to a collaborator](tutorials/09_transfer_work_to_a_collaborator.md): provide an evidence-rich handoff.

## Continue later: advanced coordination

The core route above is complete on its own. After it, the optional [advanced workstream coordination route](advanced/index.md) uses a synthetic methods, checking, and explanation case to teach dependencies, selective invalidation, and responsibility transfer. It ends with a documentary automation outlook; no agent or harness execution is required.
