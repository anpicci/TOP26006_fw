# Permissions and effects

[AGENTS.md — Scope, effects and capability](../../AGENTS.md#scope-effects-and-capability) controls repository and capability permissions. A prompt must identify the exact writable repository, paths, and effects; all other repositories remain read-only by default. A local profile path, registry entry, working credential, or executable creates no permission.

Separate grants govern network use, remote Git write, PR/MR write, merge, remote branch deletion, production, environment change, storage output, and cleanup. An allowed local commit is distinct from a remote push; consult [Git lifecycle — Conditional prompt fields](../../governance/contracts/git_lifecycle.md#conditional-prompt-fields) for the applicable Git effect and [AGENTS.md — Required reading router](../../AGENTS.md#required-reading-router) for other action contracts. Current [provider compatibility](provider_compatibility.md) limits concrete tool assumptions. See [bounded authorization](../how_to/authorise_a_bounded_change.md) for the task-oriented route.
