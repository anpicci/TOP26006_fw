# Provider compatibility status

**Reference; documentary snapshot: 2026-10-23.** This matrix separates provider documentation from installation evidence. **DOCUMENTED** means an official provider page describes a mechanism; it does **not** mean TOP26006_fw has tested it locally. **DOCUMENTED_VERSION_CONDITIONAL** and **DOCUMENTED_SURFACE_CONDITIONAL** carry the stated condition. **NOT_LOCALLY_TESTED** means no local runtime qualification was performed here. **NOT_VERIFIED** means neither current documentation nor a local observation establishes the exact proposed behavior. **NOT_APPLICABLE** means the mechanism does not supply that responsibility.
