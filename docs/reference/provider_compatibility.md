# Provider compatibility status

**Method portability:** the research pattern—question, bounded task, evidence, independent review, human acceptance—is intended to be adaptable across providers.

**Verified tool compatibility:** this round documents only the current OpenAI/Codex reference procedure. It does not qualify Anthropic or another provider. Instruction loading, permission and sandbox semantics, session/context behavior, tool interfaces, model configuration, and delegation are provider-specific. Renaming `AGENTS.md`, changing a model string, or mapping labels by analogy is insufficient to establish equivalence. Non-OpenAI mappings await the later approved provider-research round.

The profile's `provider_procedure` is a label for local facts, not a provider validation result. Read the [research workflow](../explanation/research_workflow.md) for portable concepts and live [AGENTS.md](../../AGENTS.md) for the current execution contract.
