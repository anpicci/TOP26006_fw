# Prompt contract

CPC.md owns construction; AGENTS.md owns authority, safety and the trigger
union. Universal named author inputs are prompt_id, task_revision,
decision_question, prompt_mode, delegation_policy, allowed_to_modify, read_only
and validation_ceiling. Retain the author-selected model, reasoning level,
rationale and guide versions as run configuration. Include it in the same
complete delivery, outside the explicitly delimited task text, and identify the
exact task revision. Resolve every necessary profile choice and approval before
delivery. Configuration cannot change task permissions, independence or science.
Actual authority, inputs/conventions, result, relevant
failure behavior and acceptance boundary remain required semantic content.

Name the typed repository IDs, exact task targets and installation profile.
Under the CPC/AGENTS path-binding rule, the author fixes each repository's
identity, the purpose of each branch or target, and any physical path needed
to remove ambiguity. Before an action depends on those locations or on current
repository state, the executor resolves `workspace_root` and `repo_locations`,
verifies the relevant facts, records the observations, and reopens that record.
Supply explicit paths if the profile cannot uniquely identify the authorized
target. The author need not observe every changing local fact before dispatch.
CPC supplies ordinary title, patch and final-response conventions; state
material exceptions explicitly. No scientific choice or permission can be
supplied by a default.

Non-orchestrated positive grants live only in heavy_command_permissions with
outer branch_policy. Orchestrated workflows prohibit those outer fields:
stage_branch_policy and stage_effect_permissions govern each stage and the
workflow_effect_envelope grants nothing. Activity-based orchestration,
long-horizon, production, Git, evidence and model triggers retain their fields.
Editing, checking and committing within one coding task do not by themselves require an orchestrated workflow.

Apply CPC’s single graph construction rule, including shared unique text/node
IDs, Mermaid-only visualization, joins/partial/iteration semantics and distinct
observed status. This reference adds no second graph authority.
Continuations retain current closure/delta/invalidation/checks-not-to-repeat
fields. Optional methods supply preserved stable procedure, never a second
mandate or hidden permissions. Mechanical lint is not governance completeness,
execution, qualification or owner/scientific acceptance.

[Manual authoring](../how_to/write_a_prompt_manually.md) and
[mechanical validation](../how_to/validate_a_prompt_before_execution.md) are
reader guides; current master governance remains the dispatch authority pending
adoption of this candidate.

When a task needs existing operational references or recurring procedure, use
the [workbook/playbook entrance](../operations/index.md) selectively. Entries
identify native inputs and reusable knowledge; they do not supply a second
mandate, effects or scientific choices. The run report retains material
consumed entry/source revisions and the original input/method content.
